# 🛠️ FiveM Automatic Cache Cleaner

[![Developer](https://discord.gg/kevdevstudio)

Un tool leggero, sicuro e automatico sviluppato da **Kev Dev Studio** per pulire la cache di FiveM in un solo click, ottimizzare le prestazioni di gioco e risolvere i crash visivi.

---

## 🇮🇹 Descrizione in Italiano

Sei stanco di crash improvvisi, texture che non caricano (buchi nella mappa) o cali di FPS mentre giochi su FiveM? La maggior parte di questi problemi è causata da file di cache obsoleti o corrotti. 

Questo tool automatizza l'intero processo di pulizia: non dovrai più cercare manualmente le cartelle nascoste nel tuo computer (`%localappdata%`). Fa tutto lui in meno di 3 secondi, in totale sicurezza.

### ✨ Caratteristiche principali:
* **Pulizia in 1 Click:** Avvia il tool e lascia che faccia il lavoro sporco.
* **Ottimizzazione FPS:** Ripristina il corretto caricamento delle texture di gioco.
* **Sicuro al 100%:** Elimina solo i file spazzatura della cache. **NON** tocca i tuoi dati personali, le impostazioni di gioco o le mod grafiche.
* **Leggero & Veloce:** Non richiede installazione complessa.

---

## 🇬🇧 English Description

Tired of sudden crashes, textures not loading (falling through the map), or FPS drops while playing FiveM? Most of these issues are caused by outdated or corrupted cache files.

This tool automates the entire cleaning process. You no longer need to manually navigate through hidden computer folders (`%localappdata%`). It safely does everything for you in less than 3 seconds.

### ✨ Key Features:
* **1-Click Cleaning:** Run the tool and let it do the dirty work.
* **FPS Optimization:** Fixes streaming issues and missing map textures.
* **100% Safe:** Only deletes unnecessary cache files. It **DOES NOT** touch your personal data, game settings, or graphic mods.
* **Lightweight & Fast:** No complex installation required.

## 🚀 How to Use / Come Usare

1. Scarica l'eseguibile dall'area **Releases** di GitHub (o richiedilo nel nostro Discord).
2. Chiudi completamente FiveM e GTA V.
3. Avvia il file `FiveM_Cache_Cleaner` (esegui come amministratore se necessario).
4. Fatto! La tua cache è pulita. Ora puoi avviare FiveM e goderti un gioco più fluido.
